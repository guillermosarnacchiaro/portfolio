# Definición del proyecto

## Objetivo

Crear un portafolio premium para Guillermo Sarnacchiaro que comunique profesionalismo, criterio visual y capacidad para construir productos web reales. Su objetivo comercial es generar entrevistas laborales y consultas de potenciales clientes.

## Propuesta de valor

El portafolio no será una galería genérica ni una plantilla decorada. El sitio y sus casos de estudio deberán demostrar cómo Guillermo analiza problemas, toma decisiones técnicas y desarrolla soluciones completas. WordWork será inicialmente el proyecto principal.

## Audiencias

- Reclutadores y responsables de contratación.
- Líderes técnicos que evalúan calidad de implementación.
- Clientes que necesitan una aplicación o presencia web.

## Principios del producto

- Elegante: jerarquía visual clara, composición sobria y detalles cuidados.
- Profesional: contenido verificable, redacción precisa y navegación predecible.
- Moderno: tecnología vigente sin depender de efectos pasajeros.
- Minimalista: cada elemento debe tener una función.
- Técnico: los proyectos deben explicar problema, proceso, solución y resultado.
- Accesible y rápido: movimiento respetuoso, navegación por teclado y carga eficiente.

## Dirección visual

Tomar como referencia la claridad de Vercel, la narrativa de Stripe, la precisión de Linear, la jerarquía de Apple y el carácter de Raycast. Estas referencias orientan principios; no se copiarán composiciones ni componentes.

## Tecnología

- React 19 y Vite.
- Tailwind CSS para el sistema visual.
- Framer Motion para animaciones posteriores y discretas.
- React Router para permitir crecimiento a casos de estudio individuales.
- React Icons para iconografía consistente.
- Git y GitHub para control de versiones.
- Vercel como destino de despliegue.

## Alcance de la primera versión

La primera versión incluirá navegación, Hero, Sobre mí, Habilidades, Experiencia, Proyectos, Trayectoria, Estadísticas verificables, Certificados, Contacto y Footer. Tema, contenido definitivo, animaciones e integraciones se incorporarán en etapas posteriores.

## Criterios de éxito

- La propuesta profesional se entiende en menos de diez segundos.
- WordWork presenta contexto, decisiones y aportes, no solo una captura.
- Todas las funciones se pueden utilizar con teclado y en pantallas desde 320 px.
- No existen métricas, niveles ni experiencia sin respaldo real.
- La versión de producción supera las revisiones de accesibilidad, SEO y rendimiento acordadas antes del lanzamiento.

## Fuera del alcance inicial

Blog, terminal interactiva, cursor personalizado, partículas, estadísticas automáticas de GitHub, internacionalización y panel de analítica. Se evaluarán después de validar la primera versión.
